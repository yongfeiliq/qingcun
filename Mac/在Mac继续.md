# 在 Mac 上继续轻存修复

这是 2026-09-28 从 Windows 当前工程导出的接续资料。它是项目源码与故障复现包，不是已经修好的新安装包，也不导入聊天数据库。

## 给用户的操作
1. 将「轻存-Mac接续开发包-20260928.zip」传到 Mac，完整解压到文稿中的固定位置。
2. 在 Mac Codex 中添加/打开本地项目，选择解压出来的「轻存-Mac接续项目」文件夹；选择本地执行。
3. 把「发给Mac的Codex.txt」的内容发送给新任务。无需再解释此前所有需求。
4. Mac Codex 应先读取本文件、MAC_HANDOFF.md、AGENTS.md，检查系统日志，在 Mac 上复现并完成修复和验证。

只打开这份文档或登录相同账号，不会让 Windows 本地工程自动成为 Mac 的可编辑工程。本包用于交接项目状态和已确认需求，并非承诺原任务的聊天界面自动同步。
