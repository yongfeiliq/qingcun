# 轻存 2.3.14

在 Eagle 插件面板打开轻存，在「下载入库」粘贴作品链接下载。首次安装请参阅安装说明.html。

- 浏览器助手与本机组件一起提供；首次在 Chrome / Edge 扩展管理页加载并允许网站访问，后续保持浏览器运行即可自动连接。
- 浏览器助手在后台同步已授权的平台访问状态，支持 YouTube、Vimeo、bilibili、抖音、TikTok、Instagram、Pinterest、Behance、新片场；网站自身的登录和播放限制仍以平台规则为准。
- 多资源库在「自动入库 → 选择资源库」选择；库离线则保留暂存，不切换到其它库。
- 视频、原声音、原平台标签、作品简介和来源一同处理；资料受平台权限与公开信息限制，读取失败明确提示。人工标签、备注、评分和文件夹保留。
- 入库并完整 SHA-256 核验通过后清理暂存与自动附带资料；字幕、手改文件及主动导出内容保留。
- 包含已有素材整理、图片分析、整片中文类型建议、字幕导出及烧录。智能分析默认关闭，需启用时安装并登录官方 Codex；素材画面会发送给 OpenAI，使用自己的额度。建议确认后写入 Eagle。
- 下载不要求配置模型。升级保留设置，新电脑自行登录网站并迁移 Eagle 资源库。

未商业签名的开发分发包；系统版本与平台在线实测范围以随包记录为准，不能保证所有平台和所有链接均可下载。
