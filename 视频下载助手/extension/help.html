轻存 2.3.14 · Windows 安装

64 位 Windows 10 / 11，Eagle 4+。

安装

  1. 先安装并打开 Eagle，选择资源库。结束任务，退出 Eagle。
  2. 双击对应版本的轻存 Windows 安装包，点击“开始安装”，保留浏览器扩展选项。下载引擎、FFmpeg、FFprobe、Deno 均在包内；下载不需要另装 Python、Node.js 或 .NET 8。
  3. 在 Eagle 插件安装提示中点击“安装”或更新。如果 Eagle 尚未安装，先安装 Eagle，再点击安装器的“安装 Eagle 插件”。

首次连接浏览器

  1. 在安装器点击“打开 Chrome”或“打开 Edge”，扩展路径会自动复制。
  2. 打开“开发者模式”，点击“加载已解压的扩展程序”。文件窗口地址栏粘贴路径，回车并选择文件夹。
  3. 轻存扩展“详情 → 网站访问权限”选择“在所有网站上”；已安装的扩展点击圆形重新加载按钮。

扩展位置：%LOCALAPPDATA%\QingcunVideo\extension

首次 Eagle、浏览器安装确认仍由本人完成。安装器不修改浏览器个人资料、企业策略或系统保护。支持 Chrome / Edge。

使用

  • 在 Eagle 插件面板打开“轻存”，粘贴作品链接开始下载。轻存会在后台使用已获授权的浏览器访问状态；网站要求登录或限制访问时，仍需在浏览器完成网站自身验证。
  • 多个资源库：在“下载入库 → 自动入库 → 选择资源库”自主选择。旧素材留在原库；库离线时保留暂存，不自动存到别的库。
  • 标签保留原名，分类依据作品资料；读取不完整时明确提示，不补造标签。原视频入库且完整哈希核验通过后清理暂存，长期文件由 Eagle 保管。
  • 已有素材、整片类型分析、图片分析、字幕导出和烧录入口均已包含。智能分析全新安装默认关闭；需要时安装并登录官方 Codex，打开设置中的分析开关。分析会发送素材画面给 OpenAI，使用自己的额度；类型建议确认后才写入 Eagle。

升级与换电脑

升级前结束任务，退出 Eagle。安装保留已有设置、素材、人工标签、备注和文件夹。安装包不携带资源库、登录凭据或密钥；新电脑需要自己的 Eagle、资源库和网站登录。安装后重启 Eagle，浏览器已装扩展则重新加载一次。
