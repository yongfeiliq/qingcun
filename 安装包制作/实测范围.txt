轻存 2.3.14 · Windows 开发者模式安装包
日期：2026-10-14

安装包包含 Eagle 插件、本地下载组件、yt-dlp、FFmpeg、FFprobe、Deno、Chrome/Edge 可加载的扩展源码及安装说明。安装程序会把扩展放在用户目录；首次使用需在浏览器扩展管理页打开“开发者模式”并加载该文件夹，已有扩展升级后点一次“重新加载”。

本机验证通过：
- 十个平台的单条视频链接规范化、混合批量提交与浏览器会话域名隔离；一条失败不会终止后续链接。
- Behance 作品页内嵌 YouTube、Vimeo 的读取与传递；实际 Behance 样本包含的两段 YouTube 视频均已下载入库 Eagle。
- 指定 Vimeo 1101784155 已使用原作品链接下载，含视频和音轨，Eagle 只保存一份。
- 指定 X 帖子视频已下载入库；YouTube、Bilibili、Instagram、Pinterest、新片场有此前的本机成功下载记录。
- TikTok 官方公开示例在本机完成了在线解析测试，未实际写入 Eagle。
- Eagle 真实资源库的测试条目验证了原声预览、跳转、标签与简介、来源字段、哈希核验、暂存和附带资料清理；测试条目已移入回收站，原素材未修改。
- 智能分析开关、片子类型确认流程、浏览器弹窗启动和安装包内容均做了本地回归。

访问限制：抖音两条公开示例在本机返回网站 HTTP 403，浏览器同步 Cookie 后仍不能下载；不能宣称抖音实时下载已通过。登录状态、地区、作品权限和平台变更也可能影响其他链接。遇到限制时插件会保留失败信息，不会把失败任务算成成功。

此包仅适用于 64 位 Windows 10/11。它不包含用户的视频、Eagle 资源库、网站 Cookie、账号或模型密钥。其他电脑须自行安装 Eagle、打开资源库，并在其浏览器中完成网站要求的登录或验证。macOS 版未纳入此 Windows 包；此前 Mac 预览包存在实机启动问题，本次不能标为已修复或可用。
