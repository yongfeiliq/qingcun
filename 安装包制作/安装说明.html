QINGCUN · 2.3.14 · WINDOWS

安装一次，开始收藏参考片。

Eagle 是主入口。浏览器扩展是网页下载的快捷入口，两者共用下载组件和资料。

① 在 Eagle 中确认安装

  1. 新电脑先安装 Eagle 4 或更新版本，打开准备收藏视频的资源库。
  2. 双击 轻存一体安装-v2.3.14-Windows.exe，点击开始安装。无需管理员权限，无需另装 Python、Node.js 或 FFmpeg。
  3. 程序会打开 Eagle 的插件安装提示，点击安装。没有自动打开时，点安装程序里的安装 Eagle 插件。
  4. 打开 Eagle 插件面板，进入轻存 · 参考片入库。首次使用时绑定当前打开的资源库，请先选对资源库。

已有 Eagle 图片与视频可在插件的已有素材打标签页面读取，批量补标签或识别片子类型。以后直接粘贴视频链接下载，完成后自动进入轻存 → 分类 → 品牌。保持 Eagle 运行，即可自动同步。

② 添加浏览器快捷入口（可选）

经常从网页、作品页或内嵌播放器下载时，建议安装。只在 Eagle 粘贴普通视频链接，可以暂时不安装。

  1. 在安装程序点击打开 Chrome或打开 Edge。程序会打开扩展管理页，并复制扩展文件夹路径。
  2. 开启开发者模式，点击加载已解压的扩展程序。
  3. 在文件夹选择窗口的地址栏粘贴下方路径，回车后选择此文件夹。
  4. 在浏览器扩展菜单中，将轻存固定。不要直接双击扩展里的 HTML 页面。

换电脑后设置什么？

默认保存到新电脑用户的下载 / 轻存视频，可在插件设置中更改位置。

智能分析默认关闭，无需配置 Codex 即可下载、入库和整理标签。需要时在设置中打开“启用 Codex 分析”；升级会保留开关选择，不要求重新配置。

安装包不含旧电脑的视频、资源库、登录信息和密钥。网站登录由新电脑自行建立。

已有视频如何迁移？

请另行迁移 Eagle 资源库，分类、品牌文件夹、素材和 Eagle 标签都随资源库保留。安装包不携带这些私人资料。

再次运行安装器会保留已有视频、标签和个人设置。更新前请完成下载与分析，关闭预览及 Eagle。

2.3.14 更新内容

打开新版轻存后，会将“轻存参考片”改为“轻存”、“汽车交通”改为“汽车”，沿用原文件夹和素材。新增手机、手表分类，并检查旧的自动待分类素材；手动分类保留。升级后请重新打开 Eagle 和轻存，浏览器扩展点一次重新加载。

本版修复混合批量下载：单条失败后继续处理后续链接；Behance 作品内嵌的 YouTube、Vimeo 视频也会按各自平台会话读取。Vimeo 下载使用原作品链接，避免指定视频的播放器地址返回 401。网站仍可能按作品权限和当前访问状态拒绝下载，详见“实测范围.txt”。

Eagle 入库并核验成功后，自动清理下载暂存视频、自动附带资料和空目录，长期视频由 Eagle 保存。

常见情况

Eagle 没有打开：先正常打开 Eagle，或把安装按钮打开的文件夹中的 .eagleplugin 文件交给 Eagle 安装。

扩展无法连接：重新运行安装器，并在扩展管理页给轻存点重新加载。Eagle 与浏览器需使用同一个 Windows 用户。

安装后可以删除 EXE 吗？可以，程序已复制到 %LOCALAPPDATA%\QingcunVideo。请保留这个目录。

系统显示未知发布者：这是未做商业签名的本地安装包。核对文件来源及随附校验值；若系统或单位策略阻止运行，请遵守对应提示，无需关闭系统保护。

支持 64 位 Windows 10 / 11，Eagle 4+。包含 yt-dlp、FFmpeg、Deno 及相应许可证。macOS 请勿使用此 Windows 安装程序。

图片标签：主体、景别、视角、构图、冷暖色调、光线、表现形式、视觉风格。图片与视频均可在“已有素材打标签”中批量处理，确认后写回 Eagle。图片支持 JPG、PNG、WebP、GIF、BMP、TIFF、AVIF；GIF 和多页图片使用首帧。
